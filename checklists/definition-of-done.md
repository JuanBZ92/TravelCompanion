# Definition of Done

A task using the `travel-ai-assistant` skill is not complete until:

- [ ] Backend endpoint compiles.
- [ ] Endpoint is authenticated.
- [ ] Orchestration path is covered by tests.
- [ ] Structured response contract is documented.
- [ ] MAUI can render at least one response with cards.
- [ ] No API keys are present in mobile code.
- [ ] No model-generated reservation data is treated as truth.
- [ ] Recommendation explanations include concrete reasons.
- [ ] Tool failures have graceful fallback behavior.
- [ ] Ranking logic is deterministic and testable.
- [ ] Security/privacy checklist has been reviewed.
